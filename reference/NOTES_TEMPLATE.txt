NOTES TEMPLATE — copy this structure for every new topic file.
(Delete this instructions block before saving the real notes file.)

File naming: use the exact sub_skill name in lowercase with underscores,
e.g. "time_and_distance.txt", so it matches the sub_skill tag used in
the question bank and the prerequisite graph.

Aim for 3-4 short paragraphs per topic, similar in length to
percentages.txt and profit_loss.txt. Structure each topic as:

--------------------------------------------------------------------
PARAGRAPH 1 — Definition
What is this concept, in plain terms? Define any new terms it introduces.

PARAGRAPH 2 — Core formula(s)
State the main formula(s) needed to solve problems in this topic.
Show one small worked example applying the formula with real numbers.

PARAGRAPH 3 — Common mistake or trap
What's the #1 thing students get wrong in this topic? This is the
single most valuable paragraph for the tutoring system, since it's
exactly what a student who got a question wrong needs to hear.

PARAGRAPH 4 (optional) — A trickier variation
If the topic has a harder variant (e.g. successive percentage changes,
marked price vs cost price), explain it here with a short example.
--------------------------------------------------------------------

Quality bar: read percentages.txt and profit_loss.txt in this same
folder before writing your first one, to match the tone and level of
detail. Each paragraph should be genuinely useful on its own if
retrieved in isolation — the tutoring pipeline may only pull ONE
paragraph at a time, not the whole file, so don't rely on earlier
paragraphs to make later ones make sense.
